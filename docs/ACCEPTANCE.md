## Manual acceptance steps

1. On clean Windows 10 22H2 x64 and Windows 11 x64, disconnect the network; install Soundshark-Setup-x64.exe as a standard user. Confirm local import, selected-output loopback, playback and Library save without .NET/FFmpeg on PATH. Test shortcuts and 100%, 150%, 200% Windows display scaling, including moving across monitors.
2. Editor: capture speech/music and long silence; unplug the output device; confirm all received audio and silence remain. Drop MP3/WAV with Unicode names. Trim the middle, trim all, repeat Undo/Redo; originals must be unchanged. Kill the app with unsaved changes and recover.
3. Booth: record with global Discord mode off, block the UI briefly, inspect native WAV frame count ≤5×native rate; stop early. Deny/re-enable mic access and unplug during capture. Confirm no microphone monitoring, no app preview during either type of recording, and separate workspace recovery.
4. Export files just below/at/over five seconds at every bitrate; inspect ffprobe encoded duration, actual file length and audio-only streams. If padding exceeds five seconds, ensure an actionable trim message and unchanged speech. Try duplicate names, cancel mid-process, fill destination disk, and verify no partial Library MP3 appears.
5. Library: verify immediate tiles after every export, external add/modify/rename/delete, search, one preview at a time, full-length previews in either Discord mode, edit as a fresh Editor workspace and explicit rename/delete/overwrite choices.
6. Converter: batch mixed codecs, corrupt input, long Discord-ineligible audio, duplicate destinations and cancellation; each failure must remain individually visible and editable.
7. Online: import one public YouTube video, one Short and one TikTok. Reject playlists, live/upcoming streams and sign-in content. Cancel downloads. Update downloader tools, then roll back and inspect the saved version manifest.
8. Upgrade/uninstall: verify Start Menu/optional desktop shortcut behavior, and that exported Library files survive both operations. Upload a validated MP3 to Discord manually.
